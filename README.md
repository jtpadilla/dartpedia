# dartpedia

CLI para buscar articulos de Wikipedia desde la terminal, construido siguiendo el [tutorial oficial de Dart](https://dart.dev/learn/tutorial).

## Uso

```bash
cd cli
dart run bin/cli.dart search <titulo-del-articulo>
dart run bin/cli.dart version
dart run bin/cli.dart help
```

## Requisitos

- Dart SDK `^3.12.1`
